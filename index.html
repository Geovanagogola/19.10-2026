O que é Criptografia de Letras?

A criptografia é uma técnica utilizada para transformar informações em um formato que dificulta sua leitura por pessoas não autorizadas. Um dos métodos históricos mais simples é a Cifra de César.

Como funciona? Cada letra do texto original é deslocada um número fixo de posições no alfabeto. Neste exemplo, utilizamos um deslocamento de 3 posições: A vira D, B vira E, C vira F e assim por diante.

Observação: a Cifra de César é um método educativo e não deve ser utilizada para proteger informações reais.

Explicação do Código Desenvolvido

Para fazer este protótipo funcionar, utilizamos JavaScript:

  • Capturamos o conteúdo digitado usando document.getElementById().
  • Percorremos os caracteres da mensagem com um laço de repetição for.
  • Identificamos as letras do alfabeto e deslocamos cada uma em três posições.
  • Utilizamos o operador módulo % 26 para retornar ao início do alfabeto quando necessário.
  • Exibimos o resultado na página sem precisar recarregá-la.
